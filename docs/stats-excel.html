Chapter 1: Data Collection

What This Chapter Is About

Good statistics starts with good data. Before any analysis, you need to know where your data came from, how it was collected, and whether it is representative of the population you care about. In agricultural economics, this means understanding farm surveys, USDA datasets, and sampling designs for crop yield studies.

Key Excel Skills

Task Excel Tool / Function
Enter and label a dataset Manual entry with row/column headers
Generate random numbers =RAND() and =RANDBETWEEN(low, high)
Select a simple random sample RAND() + RANK() to assign random order
Sort data Data → Sort
Filter rows by condition Data → Filter

Step-by-Step: Simple Random Sampling

Suppose you have a list of 200 farms in Lubbock County and you want to randomly select 30 for a survey.

  1. In column A, enter farm IDs 1 through 200.
  2. In column B, type =RAND() in cell B2 and drag it down to B201. This assigns each farm a random number.
  3. In column C, use =RANK(B2, $B$2:$B$201, 1) to rank farms by their random number.
  4. Sort the entire table by column C ascending.
  5. The first 30 rows after sorting are your simple random sample.

Types of Sampling Designs

  • Simple random sampling: Every unit has an equal chance — use RAND() as above.
  • Stratified sampling: Divide farms by size (small, medium, large), then sample randomly within each stratum using RANDBETWEEN.
  • Systematic sampling: Select every kth farm from a sorted list. Compute k = N/n (e.g., every 7th farm if N=200, n=30).

Common Mistake

Using RAND() without freezing the value means your sample changes every time Excel recalculates. Always paste as Values Only before sorting.

What This Chapter Is About

  1. Enter corn yields (bu/acre) in column A. Enter bin edges (80, 100, 120, 140, 160, 180) in column B.
  2. Go to Data → Data Analysis → Histogram.
  3. Set Input Range to column A and Bin Range to column B. Check Chart Output. Click OK.

Shapes to Recognize

  • Symmetric / Bell-shaped: values cluster around the center.
  • Right-skewed: long tail to the right — common in farm income data.
  • Left-skewed: long tail to the left.
  • Bimodal: two peaks — may indicate two sub-populations (irrigated vs. dryland).

Chapter 5: Probability

What This Chapter Is About

Probability underpins all of statistics. Excel lets you compute empirical probabilities directly from data using COUNTIF and build contingency tables with PivotTables.

Key Excel Skills

Task Excel Tool / Function
Count outcomes meeting a condition =COUNTIF(range, criteria)
Count with two conditions =COUNTIFS(r1, c1, r2, c2)
Compute a proportion = count / COUNTA(range)
Complement rule = 1 - P(A)
Contingency table Insert → PivotTable

Step-by-Step: Empirical Probability from Data

Suppose you have 300 farm records. Column A = Irrigation (Yes/No); Column B = Above-Average Yield (Yes/No).

  1. =COUNTIF(A2:A301, "Yes") → farms using irrigation.
  2. =COUNTIFS(A2:A301,"Yes", B2:B301,"Yes") → irrigated farms with high yield.
  3. Divide each count by 300 for probabilities.
  4. Conditional probability: P(High Yield | Irrigation) = P(Both) / P(Irrigation).

Constructing a Contingency Table

Insert → PivotTable with Irrigation as rows, Yield Category as columns, and Count of farms as values. Row and column totals give marginal probabilities.

Checking Independence

Two events A and B are independent if P(A and B) = P(A) × P(B). Compute both sides in Excel and compare.

Chapter 6: Discrete Probability Distributions

What This Chapter Is About

Some outcomes are counts: diseased plants per field, farms applying for a subsidy, defects per harvest batch. The binomial and Poisson distributions model these. Excel has built-in functions for both.

Key Excel Skills

Task Excel Function
Binomial P(X = k) =BINOM.DIST(k, n, p, FALSE)
Binomial P(X ≤ k) =BINOM.DIST(k, n, p, TRUE)
Poisson P(X = k) =POISSON.DIST(k, lambda, FALSE)
Poisson P(X ≤ k) =POISSON.DIST(k, lambda, TRUE)
Expected value (discrete) =SUMPRODUCT(values, probabilities)

Step-by-Step: Binomial Distribution

An extension survey finds 40% of small farms adopt a new pest-control method. You sample 10 farms. P(exactly 4 adopt)?

  1. =BINOM.DIST(4, 10, 0.4, FALSE) → 0.2508
  2. P(at most 4): =BINOM.DIST(4, 10, 0.4, TRUE) → 0.6331
  3. P(more than 4): =1 - BINOM.DIST(4, 10, 0.4, TRUE) → 0.3669

Building a Probability Distribution Table

  1. Column A: k values 0 through 10.
  2. Column B: =BINOM.DIST(A2, 10, 0.4, FALSE) dragged down.
  3. Insert a Bar Chart of columns A and B to visualize the distribution.
  4. Check: =SUMPRODUCT(A2:A12, B2:B12) should equal n × p = 4.

Poisson Distribution

A field averages 3 pest infestations per season. P(X = 5)?

  • =POISSON.DIST(5, 3, FALSE) → 0.1008
  • P(X ≤ 5): =POISSON.DIST(5, 3, TRUE) → 0.9161

Chapter 7: The Normal Probability Distribution

What This Chapter Is About

The normal (bell-shaped) distribution is the cornerstone of statistical inference. Crop yields, soil nutrient levels, and many economic variables follow approximately normal distributions.

Key Excel Skills

Task Excel Function
P(X ≤ x) for normal distribution =NORM.DIST(x, mean, sd, TRUE)
Find x given P(X ≤ x) = p =NORM.INV(p, mean, sd)
Standardize: z = (x − μ) / σ =STANDARDIZE(x, mean, sd)
P(Z ≤ z) standard normal =NORM.S.DIST(z, TRUE)
Find z given probability =NORM.S.INV(p)

Step-by-Step: Computing Normal Probabilities

Wheat yields: μ = 45 bu/acre, σ = 8 bu/acre.

  • P(X < 50): =NORM.DIST(50, 45, 8, TRUE) → 0.7340
  • P(X > 55): = 1 - NORM.DIST(55, 45, 8, TRUE) → 0.1056
  • P(40 < X < 55): =NORM.DIST(55,45,8,TRUE) - NORM.DIST(40,45,8,TRUE) → 0.6540

Finding a Percentile

What yield marks the 90th percentile?

=NORM.INV(0.90, 45, 8) → 55.25 bu/acre

Drawing the Bell Curve in Excel

  1. Column A: x values from 13 to 77 in steps of 1 (=SEQUENCE(65, 1, 13, 1) in Excel 365, or type manually).
  2. Column B: =NORM.DIST(A2, 45, 8, FALSE) dragged down.
  3. Insert a Line Chart using columns A and B. This draws the bell curve for your distribution.

Checking Normality

From the Descriptive Statistics output (Chapter 3): Skewness near 0 and Excess Kurtosis near 0 suggest normality. A skewness above 1 or below −1 indicates significant departure from normality.

Chapter 8: Sampling Distributions

What This Chapter Is About

A statistic like the sample mean x̄ is itself random — it changes with each new sample. Its sampling distribution describes that variability and is what makes confidence intervals and hypothesis tests valid.

Key Concepts

The Central Limit Theorem (CLT): For large enough n, the distribution of x̄ is approximately normal with mean μ and standard error σ/√n — regardless of the population’s shape.

Step-by-Step: Simulating the CLT in Excel

  1. In Sheet1, column A (rows 1–1000): enter =RANDBETWEEN(1, 100) for a uniform “population.” Freeze values (Copy → Paste Special → Values).
  2. In Sheet2, create a 200-row × 30-column table. Each cell: =INDEX(Sheet1!$A$1:$A$1000, RANDBETWEEN(1,1000)) — this draws 30 random values per row (200 samples of n = 30).
  3. In column AE of Sheet2: =AVERAGE(A2:AD2) for each row — these are 200 sample means.
  4. Build a Histogram of those 200 means. Even though the population was uniform (flat), the histogram of means looks approximately bell-shaped — that’s the CLT.

Standard Error

  • SE = σ/√n (if population SD is known)
  • SE ≈ s/√n (estimated from sample)
  • From Descriptive Statistics output: the Standard Error row gives s/√n directly.

Larger n → smaller SE → narrower sampling distribution → more precise estimates.

Chapter 9: Estimating the Value of a Parameter

What This Chapter Is About

We rarely know the true population mean μ. A confidence interval uses sample data to estimate a plausible range for μ with a stated level of confidence (90%, 95%, or 99%).

Key Excel Skills

Task Excel Function / Tool
Margin of error (σ unknown, use t) =CONFIDENCE.T(alpha, stdev_s, n)
Margin of error (σ known, use z) =CONFIDENCE.NORM(alpha, sigma, n)
t critical value (two-tailed) =T.INV.2T(alpha, df)
z critical value =NORM.S.INV(1 - alpha/2)
Full CI from ToolPak Descriptive Statistics → check Confidence Level

Step-by-Step: 95% CI for Mean Yield

Sample: n = 36 farms, x̄ = 48 bu/acre, s = 10 bu/acre.

  1. SE = = 10 / SQRT(36) → 1.667
  2. t* (df = 35, two-tailed) = =T.INV.2T(0.05, 35) → 2.030
  3. Margin of error = = 2.030 * 1.667 → 3.38
  4. CI: (44.62, 51.38) bu/acre

Or use the shortcut: =CONFIDENCE.T(0.05, 10, 36) returns the margin directly.

Confidence Interval for a Proportion

42 of 100 farms adopted cover cropping. p̂ = 0.42.

  • SE = =SQRT(0.42 * 0.58 / 100) → 0.0494
  • z* = =NORM.S.INV(0.975) → 1.960
  • ME = = 1.96 * 0.0494 → 0.097
  • CI: (0.323, 0.517) — between 32.3% and 51.7% of farms adopt cover cropping.

Chapter 10: Hypothesis Tests Regarding a Parameter

What This Chapter Is About

Hypothesis testing is the formal framework for deciding whether data gives enough evidence to reject a claim about a population. Is average farm income above $50,000? Has a new fertilizer pushed average yield beyond 45 bu/acre?

Key Excel Skills

Test Excel Tool
t-statistic (manual) = (xbar - mu0) / (s / SQRT(n))
p-value (two-tailed) =T.DIST.2T(ABS(t_stat), df)
p-value (right-tailed) =T.DIST.RT(t_stat, df)
p-value (left-tailed) =T.DIST(t_stat, df, TRUE)
t critical value =T.INV.2T(alpha, df)

Step-by-Step: One-Sample t-Test

Claim: Mean corn yield in the region exceeds 42 bu/acre.

H₀: μ = 42    H₁: μ > 42   (right-tailed)

Sample: n = 25, x̄ = 45.2, s = 9.5.

Decision Rules

Comparison Decision
p-value < α Reject H₀
p-value ≥ α Fail to reject H₀

Testing a Proportion

More than 30% of farms adopted GPS-guided equipment? Sample: n = 120, p̂ = 0.38.

  • z = = (0.38 - 0.30) / SQRT(0.30*0.70/120) → 1.913
  • p-value (right-tailed): = 1 - NORM.S.DIST(1.913, TRUE) → 0.028
  • At α = 0.05: Reject H₀. Evidence supports > 30% adoption.

Chapter 11: Inference on Two Population Parameters

What This Chapter Is About

You often want to compare two groups — irrigated vs. non-irrigated farms, organic vs. conventional yields, income before and after a policy change.

Chapter 12: Additional Inferential Methods

What This Chapter Is About

This chapter covers the chi-square test for categorical data and extends linear regression to formal inference — testing whether predictors are significant and building prediction intervals.

Part A: Chi-Square Tests

Task Excel Function
Chi-square p-value (goodness-of-fit or independence) =CHISQ.TEST(observed_range, expected_range)
Chi-square critical value =CHISQ.INV.RT(alpha, df)
Chi-square statistic (manual) =SUMPRODUCT((O-E)^2/E)

Step-by-Step: Test of Independence

Question: Is crop type independent of farm size?

  1. Build a 3×2 observed table from your data using COUNTIFS.
  2. Compute expected frequencies: E = (Row Total × Column Total) / Grand Total for each cell.
  3. =CHISQ.TEST(observed_range, expected_range) → returns the p-value directly.
  4. df = (rows − 1)(columns − 1). Compare p to α = 0.05.

Part B: Regression Inference

Column What to Read

Appendix B: One-Way ANOVA

What This Chapter Is About

When comparing means across three or more groups — four fertilizer rates, three irrigation methods — use ANOVA instead of running multiple t-tests (which inflates Type I error).

Step-by-Step: One-Way ANOVA

Question: Does mean corn yield differ across four fertilizer rates (Low, Medium, High, Very High)?

  1. Organize data: each column = one group. Each row = one farm within that group.
  2. Data → Data Analysis → ANOVA: Single Factor.
  3. Input Range = all four columns. Check Labels in First Row. Alpha = 0.05. Click OK.

### Types of Sampling Designs

- **Simple random sampling**: Every unit has an equal chance — use `RAND()` as above.
- **Stratified sampling**: Divide farms by size (small, medium, large), then sample randomly within each stratum using `RANDBETWEEN`.
- **Systematic sampling**: Select every *k*th farm from a sorted list. Compute *k = N/n* (e.g., every 7th farm if N=200, n=30).

### Common Mistake

Using `RAND()` without freezing the value means your sample changes every time Excel recalculates. Always paste as **Values Only** before sorting.

4. Conditional probability: P(High Yield | Irrigation) = P(Both) / P(Irrigation).

Two events A and B are independent if P(A and B) = P(A) × P(B). Compute both sides in Excel and compare.

## Chapter 7: The Normal Probability Distribution

### What This Chapter Is About

The normal (bell-shaped) distribution is the cornerstone of statistical inference. Crop yields, soil nutrient levels, and many economic variables follow approximately normal distributions.

### Key Excel Skills

| Task | Excel Function |
|------|---------------|
| P(X ≤ x) for normal distribution | `=NORM.DIST(x, mean, sd, TRUE)` |
| Find x given P(X ≤ x) = p | `=NORM.INV(p, mean, sd)` |
| Standardize: z = (x − μ) / σ | `=STANDARDIZE(x, mean, sd)` |
| P(Z ≤ z) standard normal | `=NORM.S.DIST(z, TRUE)` |
| Find z given probability | `=NORM.S.INV(p)` |

### Step-by-Step: Computing Normal Probabilities

Wheat yields: μ = 45 bu/acre, σ = 8 bu/acre.

- **P(X < 50)**: `=NORM.DIST(50, 45, 8, TRUE)` → **0.7340**
- **P(X > 55)**: `= 1 - NORM.DIST(55, 45, 8, TRUE)` → **0.1056**
- **P(40 < X < 55)**: `=NORM.DIST(55,45,8,TRUE) - NORM.DIST(40,45,8,TRUE)` → **0.6540**

### Finding a Percentile

What yield marks the 90th percentile?

`=NORM.INV(0.90, 45, 8)` → **55.25 bu/acre**

### Drawing the Bell Curve in Excel

1. Column A: x values from 13 to 77 in steps of 1 (`=SEQUENCE(65, 1, 13, 1)` in Excel 365, or type manually).
2. Column B: `=NORM.DIST(A2, 45, 8, FALSE)` dragged down.
3. Insert a **Line Chart** using columns A and B. This draws the bell curve for your distribution.

### Checking Normality

From the Descriptive Statistics output (Chapter 3): Skewness near 0 and Excess Kurtosis near 0 suggest normality. A skewness above 1 or below −1 indicates significant departure from normality.

## Chapter 8: Sampling Distributions

### What This Chapter Is About

A statistic like the sample mean x̄ is itself random — it changes with each new sample. Its sampling distribution describes that variability and is what makes confidence intervals and hypothesis tests valid.

### Key Concepts

The **Central Limit Theorem (CLT)**: For large enough n, the distribution of x̄ is approximately normal with mean μ and standard error σ/√n — regardless of the population's shape.

### Step-by-Step: Simulating the CLT in Excel

1. In Sheet1, column A (rows 1–1000): enter `=RANDBETWEEN(1, 100)` for a uniform "population." Freeze values (Copy → Paste Special → Values).
2. In Sheet2, create a 200-row × 30-column table. Each cell: `=INDEX(Sheet1!$A$1:$A$1000, RANDBETWEEN(1,1000))` — this draws 30 random values per row (200 samples of n = 30).
3. In column AE of Sheet2: `=AVERAGE(A2:AD2)` for each row — these are 200 sample means.
4. Build a **Histogram** of those 200 means. Even though the population was uniform (flat), the histogram of means looks approximately bell-shaped — that's the CLT.

### Standard Error

- SE = σ/√n (if population SD is known)
- SE ≈ s/√n (estimated from sample)
- From Descriptive Statistics output: the **Standard Error** row gives s/√n directly.

Larger n → smaller SE → narrower sampling distribution → more precise estimates.

## Chapter 9: Estimating the Value of a Parameter

### What This Chapter Is About

We rarely know the true population mean μ. A confidence interval uses sample data to estimate a plausible range for μ with a stated level of confidence (90%, 95%, or 99%).

### Key Excel Skills

| Task | Excel Function / Tool |
|------|-----------------------|
| Margin of error (σ unknown, use t) | `=CONFIDENCE.T(alpha, stdev_s, n)` |
| Margin of error (σ known, use z) | `=CONFIDENCE.NORM(alpha, sigma, n)` |
| t critical value (two-tailed) | `=T.INV.2T(alpha, df)` |
| z critical value | `=NORM.S.INV(1 - alpha/2)` |
| Full CI from ToolPak | *Descriptive Statistics → check Confidence Level* |

### Step-by-Step: 95% CI for Mean Yield

Sample: n = 36 farms, x̄ = 48 bu/acre, s = 10 bu/acre.

1. SE = `= 10 / SQRT(36)` → **1.667**

3. Margin of error = `= 2.030 * 1.667` → **3.38**
4. CI: **(44.62, 51.38) bu/acre**

### Paired t-Test

Same farms measured before and after a soil amendment:

*Data → Data Analysis → t-Test: Paired Two Sample for Means*. Variable 1 = before yields; Variable 2 = after yields. This accounts for farm-level variation and is more powerful than the two-sample t-test when data is paired.

| Same subjects measured twice | Paired t-test |

### Reading the ANOVA Output

| Term | Meaning |
|------|---------|
| **F statistic** | Ratio of between-group to within-group variance |
| **P-value** | Probability of this F if all means are equal |
| **Between Groups SS** | Variation explained by group membership |
| **Within Groups SS** | Unexplained variation (random error) |

- p-value < 0.05 → Reject H₀ → at least one group mean differs.
- p-value ≥ 0.05 → No significant difference across groups.

### Two-Way ANOVA

Two factors (fertilizer type + irrigation level): *Data Analysis → ANOVA: Two-Factor With Replication*. This tests main effects of each factor and their interaction.
